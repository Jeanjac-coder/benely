# Benely

Copilote Marketing & Communication propulsé par l'IA pour les entreprises africaines. Voir [docs/BLUEPRINT.md](docs/BLUEPRINT.md).

## Démarrer

```bash
npm install
cp .env.example .env.local   # renseigner ANTHROPIC_API_KEY
npm run dev
```

- `/` : onboarding et génération de la stratégie.
- `/performance` : saisie des résultats par canal, écarts et réallocation budgétaire.

`npm test` lance les tests de l'optimiseur, `npm run typecheck` le typage.
